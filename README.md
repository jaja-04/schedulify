# Schedulify

Schedulify is an automated course scheduling system designed to efficiently allocate time slots for courses.

## Usage
1. Log in as the program chair.
2. Assign courses to available time slots.
3. Ensure no time conflicts before finalizing.
4. View and manage schedules.

That's it! Schedulify simplifies course scheduling with ease.
